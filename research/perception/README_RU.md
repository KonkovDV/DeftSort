# Восприятие пулов 3/6 — тестовый набор и первая оценка (2026-11-08)
Набор: Kaggle team048-render-set (T4), 160 кадров (пулы 3 и 6 × 40 раскладок × 2 вида), 640x360, HFOV 86°,
RGB + глубина мм (0 вне 0.15–6 м) + маски экземпляров. Объекты — USD организаторов (датасет dmitrijkv/team048-organiser-objects),
раскладка по правилам spawn из objects.yaml (x 0.26–0.50, y ±0.52, случайный yaw).
Ограничения паритета: камера приближённая (поза head-cam неизвестна без USD робота), стол/свет не сцена склада.

Конвейер: только глубина+RGB → облако → v4 table_plane (RANSAC) → v4 segment → 6 признаков v4 + цветовая гистограмма 4³
→ RandomForest + порог уверенности (abstain). Маски GT — только для разметки/оценки. Разбиение train/test по сидам (60/40).

Результат (test): пул 3 — порог 0.8: coverage 0.896, selective error 0.000 (n=278); пул 6 — 0.940 / 0.000 (n=217).
Плоскость найдена на 160/160 кадрах; смесей объектов в сегментах 0; фрагментация 80 из 1243 сегментов (6%: один объект → 2 сегмента, нужна склейка); медианная ошибка XY центроида 2.2 см (p95 6.9) —
относительно origin объекта, не центра bbox.
Следующее: повторить на кадрах настоящих cam_head/cam_torso после получения ассетов; добавить фрагменты/окклюзии.
