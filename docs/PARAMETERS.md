# Параметры и их происхождение

Типы происхождения:

- док: документация организатора;
- робот: URDF или геометрия робота;
- окно: примерная граница поиска (разрешено #645);
- данные: откалибровано по логам и кадрам Kaggle-прогонов (указан прогон);
- выбор: инженерное решение с обоснованием.

`[перекалибр.]` означает, что параметр нужно проверить по TRACE следующего прогона в симуляторе.
